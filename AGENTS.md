# Person Matte

Private project for local person-matte extraction and VFX compositing.
Python, ONNX Runtime, PyTorch (legacy), FFmpeg, NumPy, Pillow, and OpenCV.
Portable Windows and Apple-silicon bundles live in private GitHub Releases.

Never commit or upload the person's face, source footage, audio, generated
person imagery, or old v1.0 packages containing the BTS demo. Only the exact
reviewed room-only images and pretrained model hashes in privacy-allowlist.json
are permitted binary assets. Keep all original/output media local. Preserve
the deny-by-default ignore policy, hooks, and full-history privacy audit.
Never copy global user instructions/configuration containing credentials.

Read README.md for runtime restoration, validation limits, and local renderer
paths. Mac binaries have not been executed on Mac hardware. Do not claim they
have. Do not overwrite original videos or existing completed exports.
