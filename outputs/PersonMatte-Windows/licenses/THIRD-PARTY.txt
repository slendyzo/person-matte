PERSON MATTE - BUNDLED COMPONENTS
================================

This folder is a portable software bundle. Third-party components retain
their own licenses. The wrapper's readable source is person_matte.py.

Robust Video Matting / MobileNetV3 FP32 ONNX, model release v1.0.0
https://github.com/PeterL1n/RobustVideoMatting
https://github.com/PeterL1n/RobustVideoMatting/releases/tag/v1.0.0
Upstream GPL-3.0 license: RVM-LICENSE.txt.
Model is bundled locally; no model download occurs during use.

Python 3.13.9, official Windows x64 embeddable distribution
https://www.python.org/ftp/python/3.13.9/python-3.13.9-embed-amd64.zip
License is included at ../runtime/LICENSE.txt.

ONNX Runtime DirectML 1.24.4, official Windows CPython 3.13 wheel
https://pypi.org/project/onnxruntime-directml/1.24.4/
https://github.com/microsoft/onnxruntime
License and all third-party notices are preserved in
../runtime/Lib/site-packages/onnxruntime/LICENSE and ThirdPartyNotices.txt.

NumPy 2.5.4, flatbuffers 25.12.19, packaging 26.3, protobuf 7.36.2,
sympy 1.14.0, mpmath 1.3.0, pefile 2024.8.26
Official PyPI wheels. Their package metadata, license files and notices
are preserved under ../runtime/Lib/site-packages and *.dist-info/.
pefile is included as a small dependency-audit utility; extraction does
not execute it. Library versions and hashes are recorded in the manifest.

FFmpeg / ffprobe 8.0.1 full build, Gyan build
https://www.gyan.dev/ffmpeg/builds/
GPL v3. See FFmpeg-GPL.txt and FFmpeg-build.txt for upstream notices,
source revision, configuration, compiler and source information.
Exact upstream revision: 894da5ca7d
https://github.com/FFmpeg/FFmpeg/commit/894da5ca7d
The included executables are unmodified copies of the Gyan distribution.
FFmpeg -version prints the complete enabled-library/build configuration.

Microsoft Visual C++ runtime components
vcruntime140.dll and vcruntime140_1.dll accompany the official embedded
Python distribution. App-local msvcp140.dll and msvcp140_1.dll provide the
standard Visual C++ runtime required by DirectML. They remain Microsoft
redistributable components and are not covered by the Python wrapper.
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

Privacy: no example footage or person imagery is included.
